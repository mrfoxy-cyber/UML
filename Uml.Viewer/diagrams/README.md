# Your accepted diagrams

Copy human-reviewed JSON files into this folder if you want to keep them together. They belong to you; generator drafts should be written elsewhere.

Open the viewer and use **Open JSON** to choose a file here, or drag a file onto the page. After editing it externally, choose/drop it again. This offline viewer does not automatically scan or watch the folder.

For several connected files, use **Open project** and choose the included `garage-project` folder. Its `uml.project.json` loads one shared model, a class view, and separate parking/removal interactions and activities. See [the connected-view guide](../CONNECTED-VIEWS.md).
